# Football Online (Godot 4.7, GDScript)

Футбол по сети: ники, статистика/рейтинг, режимы 1×1, 2×2, 3×3, 4×4, комнаты для друзей по коду.
Сервер авторитетный (вся физика и ИИ считаются на сервере), клиент шлёт только ввод. Транспорт — WebSocket.

## Быстрый старт (без хостинга, 2 минуты)
1. Открой проект в Godot 4.7 → F5.
2. Введи ник → кнопка **«Создать сервер на этом ПК (LAN)»** → запустится сервер и ты зайдёшь в него.
3. Друзья в той же сети запускают игру и вводят в «Адрес сервера» IP, который показан на главном экране.
4. Если никого нет — через 20 с пустые места займут боты, так что поиграть можно сразу.
(Проверить мультиплеер на одном ПК: запусти два окна игры, в одном создай сервер, в обоих адрес `127.0.0.1`, разные ники.
В редакторе: Debug → Run Multiple Instances.)

## Интернет-сервер бесплатно (Render.com)
1. Залей содержимое этой папки в репозиторий на GitHub (Dockerfile должен лежать в корне репозитория).
2. render.com → New → Web Service → выбери репозиторий → Runtime: **Docker** → Instance type: **Free**.
3. Получишь адрес вида `https://football-xxxx.onrender.com`. Впиши в `scripts/G.gd`:
   `const DEFAULT_SERVER := "wss://football-xxxx.onrender.com"` (или игроки вводят его в поле «Адрес сервера»).
4. Если в Dockerfile не находится нужная версия Godot — поменяй `GODOT_VERSION` (например `4.4-stable`) — сервер и клиент
   лучше держать на одной версии движка.

Особенности бесплатного тарифа: сервер «засыпает» через ~15 минут без игроков, первое подключение занимает до минуты
(клиент сам повторяет попытки). Файловая система там временная — чтобы статистика НЕ пропадала, подключи бесплатное
хранилище: Firebase Realtime Database (план Spark, без карты) → в Render добавь переменную окружения
`STORE_URL = https://ТВОЙ-ПРОЕКТ-default-rtdb.firebaseio.com/football.json?auth=ТВОЙ_СЕКРЕТ`
(сервер сам читает и пишет профили по этому адресу). Без неё статистика хранится в файле и сбрасывается при перезапуске.

Запуск сервера вручную (VPS, свой ПК): `godot --headless -- --server --port=9080`.

## Как это устроено
- `scripts/net.gd` (автозагрузка Net) — и клиент, и сервер: логин по токену+нику (ник уникален), профили, рейтинг,
  комнаты, матчмейкинг, RPC. Рейтинг: победа +25, ничья +3, поражение −20 (выход из матча = поражение).
- `scripts/match_sim.gd` — серверная симуляция матча (мяч, игроки, боты, голы, голы/передачи в статистику).
- `scripts/net_game.gd` + `scenes/NetGame.tscn` — клиентская часть матча: рисует снимки сервера (30/с), шлёт ввод.
- `scripts/menu.gd` — вход, быстрая игра, комнаты по коду, лобби, статистика, смена ника.
- Режимы N×N: у каждой команды вратарь-бот + N полевых; свободные места занимают боты.

## Управление
ПК: WASD/стрелки — ход, Пробел — единственная кнопка удара: тап = удар низом, удержание дольше ~0,35 с = удар верхом.
Стоишь перед соперником с мячом — тот же Пробел отбирает мяч; подкат — если соперник чуть дальше. R — финт (белая вспышка на секунду: мяч не отобрать). Esc — меню настроек.
Вратарь (офлайн): Q/E — прыжок, Z — раш, Пробел/X — выход/выбить.
Телефон: джойстик слева, большая кнопка «УДАР», «ФИНТ» (появляется, пока мяч у тебя), «МЕНЮ» вверху справа. У вратаря — прыжки, выход и раш.
Меню: продолжить, графика (низкая/средняя/высокая), звук вкл/выкл и громкость, выход из матча. Настройки сохраняются (user://settings.cfg).
Блок: мяч, летящий в игрока, отскакивает от тела по физике; высокий мяч летит над головами.

## Правила матча (офлайн)
- Фолы при отборе и подкате, предупреждение, жёлтая и красная карточки (две жёлтые = красная, игрок удаляется).
- Штрафной и свободный удары со стенкой, пенальти за фол в штрафной.
- VAR: спорные голы, пенальти и карточки иногда проверяются с повтором эпизода (замедленно, игроки подсвечены) и решением: подтверждено или изменено (гол отменён, пенальти станет штрафным, красная станет жёлтой). Enter или кнопка ПРОПУСТИТЬ — пропустить повтор.
- Ауты, угловые, удары от ворот.
- Статистика команд: удары, отборы, финты, голы, ассисты, сейвы, фолы, карточки. Клавиша T или кнопка СТАТ — во время матча, полная таблица в конце.
- Финт: игрок подпрыгивает с белым эффектом на месте. Если на него идут в отбор — «НЕ СМОГ ОТОБРАТЬ».
- Вратарь: Z — раш.
- Боты слабее: медленнее, чаще промахиваются, вратарь реже спасает.


## Что нового в этой версии (протокол 2 — обновите и клиент, и сервер)
- **Онлайн = как офлайн.** Фолы, предупреждения, жёлтые/красные карточки, удаления, ауты, угловые, удары от ворот,
  штрафные, пенальти и статистика матча (клавиша T / кнопка СТАТ) теперь считаются на сервере (`scripts/rules.gd` —
  общий модуль и для офлайн-игры, и для сервера). Профиль и таблица рекордов хранят фолы, жёлтые и красные.
- **Стандарты руками и ногой.** Аут — бросок руками (мяч над головой), угловой/штрафной/от ворот — удар ногой.
  Стик — направление, удержание кнопки удара — сила, отпустил — исполнение. Во время стандарта все остальные
  заморожены, соперники отодвинуты: затаклить нельзя. Боты исполняют сами.
- **Кат-сцена пенальти и близкого штрафного (до ~430 px от ворот).** Камера наезжает на ворота. Бьющий выбирает
  зону (лево/центр/право × верх/низ), вратарь — куда прыгать (лево/центр/право). Выбор — стиком + кнопкой удара
  или тапом по зоне. Исход решает сервер (гол, сейв, штанга, мимо, стенка). Офлайн: если бьёт соперник, куда прыгает
  ваш вратарь, выбираете вы. Онлайн: если в команде защищающихся есть человек, он выбирает прыжок вратаря.
- **Запрос VAR (только офлайн).** После гола (около 3 с) или после того, как у вас отобрали мяч, появляется кнопка
  VAR (клавиша V). На матч 2 запроса. Гол соперника отменяется чаще, чем ваш; при отборе судья может назначить фол.
- Стрелка-индикатор направления на мяч, когда он за кадром (удобно на телефоне).
- Совместимость: `G.PROTO` повышен до 2, старые клиенты получат «версия устарела».

## Что добавлено в этой версии (офлайн-режимы: матч, тренировки)
- **Офсайд.** Игрок в чужой половине, дальше мяча и дальше предпоследнего защитника, получивший пас, — офсайд: свисток, жёлтая линия на поле, соперник бьёт свободный (непрямой, без «кат-сцены») с места нарушения. Боты не пасуют в офсайд. Вкл/выкл — на экране настроек матча. Работает и на сервере (онлайн).
- **Серия пенальти при ничьей** (5 ударов, затем до первого промаха). Бьёте и вы, и бот; в защите вы выбираете прыжок вратаря. Панель с ✓/✕ вверху экрана. Отдельный режим «Серия пенальти» есть в тренировках. Вкл/выкл — в настройках матча.
- **Разные финты** (клавиша R / кнопка ФИНТ): без стика — по кругу подманка → рулетка → рывок → разворот; со стиком: вбок — рулетка, вперёд — рывок, назад — разворот. Все дают защиту мяча на ~1 с.
- **Настройки матча**: длительность тайма (1:00–5:00), число игроков в команде (3–7 с вратарём), офсайд, пенальти при ничьей.
- **Экран выбора команды и формации** (Тренировка → любой режим): 7 команд с цветами формы, формации «защитная / сбалансированная / атакующая» для каждой стороны.
- **Музыка и комментатор**: 3 трека (Стадион, Ритм, Драйв), выбор трека, вкл/выкл — в главном меню → Настройки, на экране настроек матча и в паузе (Esc). Комментатор — субтитры внизу экрана; если в системе есть русский голос синтеза речи, фразы ещё и озвучиваются.
- **Плавные переходы**: затемнение между сценами и появление экранов меню.
- **Новые тени**: мягкие многослойные тени игроков и мяча (вторая тень при высокой графике), тень от трибун на газоне.
- **«Волна» болельщиков**: волна пробегает по периметру стадиона каждые ~30 с; после гола трибуны подпрыгивают. Включается при графике «средняя» и выше.
- Убрана строка-подсказка управления внизу экрана.

## Ограничения
- Выбор команды, формаций, длительности и числа игроков — только офлайн; онлайн-матчи используют прежние настройки (команды СИНИЕ/КРАСНЫЕ, фиксированное время).
- Серия пенальти в онлайне не реализована (по ничьей матч просто заканчивается).
- Проект не запускался в Godot при подготовке этой версии — при первом открытии проверьте консоль на ошибки и дайте редактору импортировать новые файлы `assets/music/*.wav`.
